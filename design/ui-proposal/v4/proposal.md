# UI 设计 V4
主界面：开始、设置、退出使用同一绿色按钮。开始进入选关，不直接开局。
树木底部统一落在地面上，装饰保持等比缩放。
选关：四张不同的圆角倾斜四边形底板，交替采用上宽下窄、上窄下宽和不同斜边，圆形预览直径 300，大于底板约 215 宽，超出两侧边界；标题和进度仍在底板内。
设置：音乐音量、音效音量、分辨率。默认自动，按当前显示器原生尺寸与支持模式确定分辨率；提供不超过显示器尺寸的可用分辨率选项。显示器改变时重新评估；UI 按参考画布缩放与锚点布局适配不同比例，不拉伸美术。移除全屏开关；实际窗口模式沿用游戏设置。修改即时生效并自动保存，不设应用按钮；关闭与返回均保留修改，失效的已存选项回退自动。
关内：保留原有金币、星星数量 UI 和计时，新增设置入口。静态稿中金币、数字与时间摘取已有 Game 截图，星星改为 Kit 星星图标加同风格数字；实现时复用现有组件，不复制截图。示例计数不代表实时状态。
音效候选沿用上一版；尚未试听定稿。
本次仅修改设计稿，没有修改 Unity 场景、代码、碰撞、礼物逻辑。分辨率适配尚未实现和运行验证。
