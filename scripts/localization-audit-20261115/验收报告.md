# 多语言检查与修正 — 2026-11-15

## 结果与范围

29 种语言，每种 22 条文案，共 638 条。Windows 编辑器中字体覆盖检查通过；包含语言自称、当前全部文案、数字和界面符号。1280×720、1920×1080 两次最终布局检查均 PASS，失败项为 0。当前语料没有发现缺字或方块字；不代表这些字体涵盖任意未来输入。

四个设置项（音效、音乐、分辨率、语言）按当前语言共同选字号：上限 32，在按钮安全区域内逐号寻找最大共同值。每项可按完整词换行，不能拆词。没有空格的文字片段整体保留并缩小，不擅自给泰语、缅甸语做词典切分。四项字号一致是指同一个语言界面，语言之间会因长度而不同。

统一替换文本绘制的自动断词行为，并给设置弹窗标题增加安全内边距。俄语关卡名的 пляже 保持完整，不再出现半个单词独占一行。美术背景、按钮形状及原有字体选择保持。

## 文案审核

全部 638 条已与中英文基准逐条做含义对照；8 类常用 UI 术语另与已发布的 Mindustry v146、SuperTuxKart 1.4、Minecraft Java 1.21.1 对照。详见 [术语对照](术语对照.md)、[完整文案对照 CSV](all-strings-review.csv)。参考来源 URL 保存在表中；参考词必须结合语境，音乐“播放”不能直接作为主菜单“开始”。

修改：西班牙语 Efectos → Efectos de sonido；阿拉伯语 المؤثرات → المؤثرات الصوتية，明确是音效；缅甸语分辨率从“画质”修正为 ကြည်လင်ပြတ်သားမှု。JSON 与源 TSV 已同步，逐项理由见 translation-changes.json。

27 种非英语语言找到了上述已发布游戏的术语材料；英语是源语言。缅甸语没有找到可靠的已发布游戏参考，仅参考技术材料，仍需重点母语复核。联网术语对照与本轮语义检查不等于 29 种语言的真人母语审校；所有语言均未取得真人母语签收。
