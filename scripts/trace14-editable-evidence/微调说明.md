# 第五关微调
打开 Assets/Scenes/Level05_Cave.unity。
Hierarchy 展开 Level → Terrain → Floor 01…14 → Fxx_Pieceyy。
每一块现在都有独立 SpriteRenderer 和 PolygonCollider2D。
选中后 W 移动、E 旋转、R 缩放，图像和碰撞一起改变；Ctrl+Z 撤销，Ctrl+S 保存。
多选可以一起移动。选中后按 F 聚焦。钻石、检查点、出口在 Interactions 中，调整地形时一并检查其位置。
只改 PolygonCollider2D 的 Edit Collider 会仅修改碰撞，不同步图像；普通位置与尺寸微调请用 Transform。
不要执行 ApplyTrace14 或 ApplyEditableTrace 的重新生成菜单，它会覆盖手工调整；场景是后续微调的工作源。

本次：129个地形对象，按14层分组；43处辅助落脚点。辅助点由角色净空近似路径产生，只是初步可达性适配。默认目标半径2m，但真实攀升取决于物理、出力和碰撞；尚未完成全路线实玩，不能保证所有钻石和出口已可通关。
独立Unity编译/保存通过；129块图像/碰撞包围框对齐通过。净空估算使用约.96m×1.36m包围框，存在底到顶的自由空间路径；这不是逐跳锤子通关证明。
